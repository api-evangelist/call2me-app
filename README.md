Call2Me provides a live AI interpreter and voice agents for phone calls, enabling real‑time translation and automated call handling. Users can start for free, paying as low as $0.25 per minute. The platform supports bidirectional communication, multiple languages, and 24/7 availability, targeting businesses, legal, and healthcare sectors.

**Areas:** Company · AI · Voice · Interpreter · Real-time · Payments

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Call2Me: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
